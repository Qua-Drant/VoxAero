# VoxAero 测试用例与验收

本文覆盖武大信息学部场景下的任务调度、动态选址、三维航线规划和飞行仿真。有效航线以当前场景数据、航层和碰撞规则校验为准。

## 运行方式

在项目根目录使用 Conda 环境 `VoxAero`（Python 3.11）。

```powershell
conda run -n VoxAero python --version
conda run --no-capture-output -n VoxAero pytest -q -s
```

可单独复跑调度、实景性能与 30 用例本地规则评测（无需 API Key）：

```powershell
conda run --no-capture-output -n VoxAero pytest -q tests/test_spatial_dispatch.py
conda run --no-capture-output -n VoxAero pytest -q -s tests/test_real_scene.py -k real_scene_performance
conda run --no-capture-output -n VoxAero python -m scripts.evaluate_dispatch --local-only
```

自动化测试使用本地规则和模型接口替身，可在没有模型密钥的环境复跑。配置 `.env` 启用真实模型后，可运行 `conda run --no-capture-output -n VoxAero python -m scripts.evaluate_dispatch --output eval.json` 执行本地规则与真实大模型 30 用例对照评测。

## 浏览器验收

若服务已启动，刷新 [VoxAero 本地预览](http://127.0.0.1:8001/)。若服务已停，请从项目根目录启动。

```powershell
conda run -n VoxAero uvicorn backend.main:app --port 8001
```

可打开 [服务状态](http://127.0.0.1:8001/api/health) 查看运行模式。`live_llm` 对应实际模型接口，`fallback_mock` 对应免 API Key 的本地规则模式。测试正常抵达或指定应急时，可先在「突发应急」关闭「随机应急演练」，到随机事件用例再开启。

| --- | --- | --- |
